# Visual Gifts & NFT — exteraGram plugin

Локальная визуальная симуляция для exteraGram:

- дарение подарков;
- покупка / дарение **NFT**-подарков;
- установка NFT в **витрину профиля** (настраиваемые слоты);
- **крафт** NFT из «осколков подарков» и NFT;
- визуальный баланс **Stars** и **GRAM**, который регулируется в настройках плагина.

> Всё локально: плагин ничего не покупает, не работает с блокчейном и
> не меняет реальный аккаунт. В чат уходит только текстовая плашка.

## Состав репозитория

```
extera-repo/
|-- extera-plugins.json                 # индекс каталога (схема 1)
|-- build_index.py                      # регенерация индекса
`-- plugins/
    `-- visual_gifts/
        `-- visual_gifts.plugin         # сам плагин
```

## Установка через GitHub (рекомендуется)

1. Создайте на GitHub новый **публичный** репозиторий (например `extera-plugins`).
2. Залейте в него содержимое папки `extera-repo/` (файлы `extera-plugins.json`,
   `build_index.py` и папку `plugins/`).
3. В exteraGram: **Настройки → Плагины → Каталог → + (добавить репозиторий)** и вставьте
   ссылку на ваш репозиторий, напр. `https://github.com/<ваш-логин>/extera-plugins`.
4. Когда появится плагин «Визуальные подарки и NFT», нажмите «Установить».
   Возможно, потребуется включить **Unknown sources** (неизвестные источники) в настройках плагинов.

Также репозиторий можно добавить ссылкой-джойнером:

```
https://t.me/exteraPluginRepo?git=https%3A%2F%2Fgithub.com%2F<ваш-логин>%2Fextera-plugins
```

## Установка через Telegram-канал (альтернатива)

1. Создайте публичный Telegram-канал.
2. Загрузите туда `plugins/visual_gifts/visual_gifts.plugin` как **документ** (без сжатия фото).
3. В exteraGram добавьте канал как репозиторий: **Каталог → + → ссылка канала**.
   Плагин появится в каталоге. Файл `.plugin` должен быть не больше 2 МБ.

## Обновление после правок

1. Измените код и поднимите `__version__` в плагине.
2. Перезапустите генерацию индекса:

```
python build_index.py
```

   Скрипт пересчитает `sha256`, `size` и `updated_at`. Затем запушьте изменения в репозиторий.
   Каталог в exteraGram подтянет новую версию автоматически.
